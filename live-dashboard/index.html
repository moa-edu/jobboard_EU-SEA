How this stays live. A GitHub Actions workflow runs scraper.py nightly, pulling from sources that allow automated access (EconJobMarket, THEunijobs, AcademicKeys) and writing the result to data/jobs.json, which this page fetches on load. Boards that block automated requests outright (HigherEdJobs, Chronicle of Higher Education) are deliberately not scraped — see scraper.py's header comment for why, and the per-source status above for which sources succeeded on the most recent run. The 49 listings originally compiled by hand on 2026-08-05 / 2026-10-15 are seeded in and will age out automatically after 120 days if no source re-confirms them.
